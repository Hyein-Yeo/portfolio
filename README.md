## All in WON

사업·서비스 기획력 | 2026.10.26-10.28 · 4인 팀 · 배포·발표 완료

주식 차트·뉴스·공시에 맞는 AI 질문 설계

외국인 수급은 ETF 탐색으로, 연금 기사는 IRP 안내·상담으로 이어지는 고객 여정을 기획했습니다.

기여: 서비스 기획 · 경쟁사 분석 · 수익구조 제안 · 발표자료

결과물: 팀 프로토타입 배포·발표 완료

- 사용자 문제 정의: 기존 방식 선호·효용 불확실·접근 어려움을 AI 이용 장벽으로 정리했습니다.
- UX 설계 의사결정: 차트·뉴스·공시에 맥락 질문을 제안해, 질문 작성과 AI 메뉴 탐색의 부담을 줄이도록 설계했습니다.
- 사업 연계 시나리오: 이해 이후의 고객 여정을 수급 질문 → ETF 탐색 / 연금 기사 → IRP 안내·상담으로 설계했습니다.

확인 범위: 연결 흐름을 제시한 프로토타입입니다. 실제 고객의 이해·이용 개선 효과와 거래·상담 전환은 확인하지 않았습니다.

다음 검토 - 아래 내용은 아직 수행하지 않은 계획입니다.

- 현재한계: 질문 제안이 초보 투자자의 이해와 다음 행동에 도움이 되는지는 미검증입니다.
- 다음행동: 초보 투자자에게 수급→ETF, 연금 기사→IRP 과제를 제시하고 질문 선택·설명 이해·다음 화면 이동을 관찰합니다.
- 완료조건: 과제별 선택 경로·이해한 내용·막힌 지점을 기록하고, 수정한 화면을 같은 과제로 다시 확인하면 1차 검토를 마칩니다.

## 노랑풍선 기업분석

분석·의사결정력 | 2023년 2학기 · 개인 보고서 · 작성 완료

재무지표 기반 기업분석·동종기업 비교분석

노랑풍선과 하나투어의 동기간 지표를 비교하고, 성장률의 기저효과·수익성·현금흐름을 함께 해석했습니다.

기여: 공시·재무자료 정리 · 동종기업 비교분석 · 개인 보고서

결과물: 재무지표·현금흐름·동종기업 비교분석 보고서 완성

- 재무지표 기반 기업분석: 수익성·효율성·유동성·재무안정성·현금흐름을 분석해 기업의 재무상태와 성과를 검토했습니다.
- 동종기업 비교분석 · Peer Comparison: 하나투어를 비교기업으로 두고, 같은 기간의 재무지표를 비교해 성과 차이의 원인을 해석했습니다.
- 재무지표 해석: 매출액 증가율 651.5%에는 전년의 낮은 매출이 반영됐음을 짚고, 업황 회복과 기업 고유의 성과를 구분했습니다.

확인 범위: 2023년 수업 과제입니다. 가치평가 가정·단위·계산을 재검산하기 전에는 당시 평가액을 현재의 투자 판단에 적용하지 않습니다.

다음 검토 - 아래 내용은 아직 수행하지 않은 계획입니다.

- 현재한계: 당시 가치평가의 가정·단위·계산은 재검토 대상이므로 평가액의 정확성을 확정하지 않습니다.
- 다음행동: 평가에 사용한 기준일·재무자료 단위·비교기업 배수와 산식을 원자료에 대조하고 재계산합니다.
- 완료조건: 입력값마다 출처·단위·기준일을 붙이고, 재계산값과 원문 차이를 설명한 대조표를 완성하면 1차 검토를 마칩니다.

- [원보고서 PDF](portfolio-fintech/assets/documents/analysis.pdf)

수업 평가: 우수 과제 선정·후속 수강생 참고 자료 활용은 본인 경험 기록 기준입니다.

## B.READY

협업·추진력 | 2023년 · 약 3개월 · 4인 팀 · 제안서 완성

핵심 문구를 중심으로 브랜드 경험과 팀의 방향 정렬

‘非READY-MADE, B.READY-MADE’ 아래 콘셉트스토어·체험안을 기획하고, 공동 목표에 맞춰 팀의 역할을 조율했습니다.

기여: 핵심 문구·콘셉트스토어 기획 · 팀장 · PPT·시각화 공동 제작

결과물: 브랜드 방향과 체험안을 담은 공동 제안서

- 브랜드 정체성 정립: 브랜드 이미지가 모호해, B.READY가 지향하는 남성의 아름다움을 설명할 기준이 필요했습니다.
- 핵심 메시지 기획: 非READY-MADE, B.READY-MADE — 정형화되지 않은 남성의 아름다움을 표현하고자 했습니다.
- 콘셉트·체험 기획: 이 문구 아래 콘셉트스토어와 체험·제품 추천·구매 연결 등 세부 기획안을 구성했습니다.

확인 범위: 브랜드·공간·체험을 연결한 기획 제안입니다. 매장 운영·방문객 반응·구매 효과는 검증하지 않았습니다.

다음 검토 - 아래 내용은 아직 수행하지 않은 계획입니다.

- 현재한계: 콘셉트스토어 제안 단계이므로 방문객의 브랜드 이해와 실제 구매 효과는 확인하지 않았습니다.
- 다음행동: 핵심 문구·공간·체험·제품 추천의 대응표를 만들고, 타깃 고객에게 제안서만 보여준 뒤 브랜드 인상을 확인합니다.
- 완료조건: 의도한 브랜드 의미와 고객 응답의 차이, 그에 따른 문구·체험안 수정 이유를 기록하면 1차 검토를 마칩니다.
